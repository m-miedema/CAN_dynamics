Scripts for processing data for work presented in Miedema, M., Dagenais, R., Torabi, M., Askari, E., Long, S., and Mitsis, G.D., 2026. Denoising the central autonomic network: characterizing processes jointly associated with arousal and non-neuronal physiological artefacts in dynamic fMRI analyses.

Physiological preprocessing scripts which should be used prior to the present analysis can be found [here](https://github.com/m-miedema/autonomic_preproc).

Full instructions for use to follow.
